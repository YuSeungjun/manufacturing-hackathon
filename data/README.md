# 데이터

이 디렉터리 안의 내용물은 git 에 올리지 않는다 (`.gitignore`).

승인은 **데이터셋별**이다. aihub.or.kr 로그인 → 데이터셋 페이지 → `AI 데이터 다운로드` 신청.
승인 전에는 API 가 안내문만 돌려준다(실측 확인).

```bash
export AIHUB_APIKEY=...
./scripts/aihub_tree.sh 510        # 파일 트리와 fileSn 조회 (승인 없이도 됨)
./scripts/aihub_fetch.sh labels-510
```

## 1) 데모 영상 — 「물류창고 내 작업 안전 데이터」 (510)

<https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=510>

고정 CCTV, 14개 이상 물류창고 + 위험상황 연출 영상. 바운딩박스·폴리곤 JSON, 클래스 28종
(작업자·지게차·적재물류·도크 등). 구축기관 ㈜미디어그룹사람과숲, 2021년.

**받을 파일 (전부 비분할 zip)**

| 파일 | 용량 | fileSn |
|---|---|---|
| `VL_04_설비 및 장비.zip` (라벨) | 5 MB | 62662 |
| `VL_05_운반.zip` (라벨) | 6 MB | 62663 |
| `VS_04_설비 및 장비.zip` (원천) | 4 GB | 62673 |
| `VS_05_운반.zip` (원천) | 4 GB | 62674 |

### ⚠ 4GB 를 받기 전에 라벨부터 확인할 것

구축량이 **"576,908장"** 으로 이미지 단위로 표기되어 있다. 원천데이터가 mp4 가 아니라
**추출된 jpg 프레임**일 가능성이 높다. 그 자체는 문제가 아니지만, **프레임이 연속인지**가
쓸 수 있는지 없는지를 가른다.

| 배포 형태 | 판정 |
|---|---|
| mp4 | 그대로 쓴다 |
| **연속** jpg | `ffmpeg` 로 영상 복원. 프레임별 정답 라벨이 있어 평가에는 오히려 유리 |
| **드문드문한** jpg | 추적·영상 복원 모두 불가 → 못 쓴다 |

라벨 zip 이 5MB 라 몇 초면 받는다. 받아서 이걸 돌리면 즉시 답이 나온다:

```bash
./scripts/aihub_fetch.sh labels-510
ai/.venv/bin/python -m ai.eval.inspect_labels data/aihub/510
```

`✓ 연속 프레임입니다` 가 나오면 원천 4GB 를 받는다. `✗ 드문드문합니다` 가 나오면 받지 않는다.

### 끼임 클래스는 없다

위험상황 22종에 직접적인 끼임·협착이 없다(지게차 시야 미확보 등 간접 상황). 위험구역은
우리가 직접 그리므로 **데모에는 지장이 없지만**, "끼임 정답 라벨로 로직을 채점한다"는
평가는 510 으로 못 한다. 그건 아래 71679 라벨이 필요하다.

## 2) 로직 평가 — 「스마트 제조 시설 안전 감시를 위한 데이터」 (71679)

<https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=71679>

인명사고 이벤트 클래스에 **`jam`(끼임)** 이 있다. `bump` `fall-down` `fall-off` `hit` `jam` `no-accident`.

**라벨만 받는다.**

| 파일 | 용량 | fileSn |
|---|---|---|
| `TL.zip` (Training 라벨) | 602 MB | 522641 |
| `VL.zip` (Validation 라벨) | 74 MB | 522644 |

```bash
./scripts/aihub_fetch.sh labels-71679
```

**원천 영상은 받지 않는다.** Training 원천이 `TS.z01~z13 + TS.zip` 100GB 분할압축(약 1.3TB),
Validation 이 `VS.z01 + VS.zip` 165GB 다. 분할압축이라 조각 하나만 받아서는 압축을 풀 수 없고,
가장 작은 완결 단위가 165GB 다.

구축기관은 ㈜프라코(자동차 부품 제조) 외. 페이지 어디에도 제철소·압연설비 언급이 없어
**압연 장면은 없을 가능성이 높다.** 기획서의 대비책대로 서비스 범위를 "제철소 내 이송·회전설비
끼임 예방"으로 조정하는 근거가 된다.

**샘플(경량) 데이터** 는 로그인만으로 즉시 받을 수 있다(승인 불필요). 구성이 페이지에
명시되어 있지 않아 영상 포함 여부는 열어봐야 안다. `data/aihub/71679/` 에 풀고
`inspect_labels` 를 돌려 보면 된다.

## 왜 학습에 쓰지 않는가

원천 픽셀 없이는 검출기를 학습할 수 없고, 71679 원천은 받을 수 없다. 그리고 필요도 없다 —
COCO `person` 은 26만 인스턴스로 최다 클래스이고, "여기 사람이 서 있는가"는 nano 모델도 이미
천장 근처다. 이 문제의 실제 난점은 분류가 아니라 기하(가림·원거리·반사)와
**구역 × 잔류 × 설비상태 결합 로직**이며, 그 로직은 학습 데이터가 0바이트도 필요 없다.

라벨은 대신 **로직층 평가**에 쓴다 — 검출기 출력 자리에 정답 bbox 를 그대로 넣어 상태머신만
채점한다. 검출기 mAP 는 픽셀 없이 못 재지만, 이 시스템에서 중요한 건 검출기가 아니라
결합 로직이고 그건 라벨만으로 완전히 평가된다.
